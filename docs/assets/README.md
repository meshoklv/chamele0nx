# Diagrams

Every diagram here is generated by [`generate.py`](generate.py) in both
English (`en/`) and Russian (`ru/`). To change a caption, edit the string
table at the bottom of that file and run:

```bash
python3 docs/assets/generate.py
```

No dependencies beyond the Python standard library. The output is plain
SVG with an explicit light background, which renders the same in GitHub's
light and dark themes and stays sharp at any zoom.

| File | Shows |
|---|---|
| `01-what-the-censor-sees` | Why encryption alone does not help: the traffic shape of a VPN, of real browsing, and of this protocol |
| `02-architecture` | The layers on each side, and what an observer in the middle can and cannot see |
| `03-handshake` | The connection sequence, including what happens when the cookie is wrong |
| `04-wire-format` | The five layers of wrapping around one byte, and the stream types |
| `05-shaping` | How a captured profile turns a byte stream into traffic, and how that is verified |

## Brand

The project logo lives in [`brand/`](brand/). The master is a single-path,
tintable silhouette; the light and dark variants differ only in fill colour
so the README renders in either GitHub theme.

| File | Use |
|---|---|
| `chameleon-logo.svg` | vector master, 1024×1024, `#000` fill (tintable) |
| `chameleon-logo-light.svg` | dark fill, for light backgrounds |
| `chameleon-logo-dark.svg` | light fill, for dark backgrounds |
| `chameleon-icon.png` | 1024² transparent PNG, for overlays and app icons |
