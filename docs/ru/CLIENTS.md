# Клиенты

С сервером Chamele0nX можно говорить двумя способами: клиентом командной
строки из этого репозитория и биндингами Go, которые встраиваются в
нативное приложение.

## Клиент командной строки

`chamele0nx-client` подключается к серверу и поднимает SOCKS5-прокси на
localhost. Всё, что вы направите в этот прокси, идёт через туннель;
остальное — нет. Работает и с TCP, и с UDP.

```bash
./bin/chamele0nx-client \
  -server vpn.example.com:443 \
  -secret-file ~/.config/chamele0nx/secret \
  -cookie-format wordpress \
  -port 1080
```

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `-server` | — | Адрес сервера в виде `host:port`. Обязателен. |
| `-secret` | — | Секрет пользователя в hex. Виден в `ps`; лучше `-secret-file`. |
| `-secret-file` | — | Читает hex-секрет из файла. Понимает также `$CHAMELE0NX_SECRET_FILE`. |
| `-server-id` | `chamele0nx-1` | Обязан совпадать с `-server-id` сервера; подмешивается в токен доступа. |
| `-api-path` | `/api/v1/events` | Обязан совпадать с сервером. |
| `-cookie-format` | `generic` | `generic`, `wordpress` или `django`. Обязан совпадать с сервером. |
| `-sni` | хост из `-server` | Имя TLS-сервера, которое предъявлять. |
| `-profile` | пусто | Профиль формовки в направлении к серверу. Пустое значение разрешается во встроенный `DefaultSaaSProfile`. |
| `-port` | `0` (случайный) | Локальный порт SOCKS5. |
| `-check` | выключено | Подключиться, проверить выход через туннель, напечатать результат, выйти. |
| `-check-timeout` | `30s` | Сколько ждёт `-check`, включая одно переподключение. |
| `-cover` | пусто | Идентификатор профиля прикрытия. Пустое значение разрешается в `saas-http2`, единственный скомпилированный. |
| `-log-format` | `text` | `text` или `json`. |
| `-log-level` | `info` | `debug`, `info`, `warn`, `error`. |
| `-version` | — | Напечатать сведения о сборке и выйти. |

Слушатель SOCKS5 держит свой порт всё время жизни процесса. Если туннель
под ним рвётся, клиент собирает его заново с растущей выдержкой между
попытками, а приложения сохраняют свои настройки прокси. При сетевом сбое
выдержка растёт от секунды до минуты; при отвергнутом секрете — от десяти
секунд до пяти минут, потому что повторять учётные данные, которые сервер уже
отверг, и бесполезно, и заметно.

Проверить сервер, ничего не настраивая:

```bash
./bin/chamele0nx-client -server vpn.example.com:443 -secret-file ./secret -check
```

Он покажет внешний адрес, с которого туннель выходит наружу. Если это
адрес вашего сервера — весь путь работает.

### Как пользоваться прокси

```bash
curl -x socks5h://127.0.0.1:1080 https://example.org/
```

Пишите `socks5h`, а не `socks5`: буква `h` отправляет DNS через туннель.
С обычным `socks5` ваш резолвер по-прежнему выдаёт локальной сети каждое
имя, которое вы открываете.

Firefox принимает SOCKS5-прокси сам, с включённой галкой «Proxy DNS when
using SOCKS v5». Chrome нужен ключ командной строки
`--proxy-server="socks5://127.0.0.1:1080"`. Маршрутизация всей системы
требует tun-устройства и находится вне рамок этого клиента.

## Мобильные и десктопные приложения

`mobile/` собирается через `gomobile bind` в `.xcframework` для платформ
Apple. Биндинг намеренно маленький: gomobile
пропускает через границу только простые типы.

| Вызов | Возвращает | Примечания |
|---|---|---|
| `Version()` | строку | Быстрая проверка, что фреймворк загрузился. |
| `NewClient(endpointJSON)` | дескриптор | Настройки приходят строкой JSON. |
| `Start()` / `StartOnPort(port)` | адрес SOCKS5 | Запускает цикл переподключений. |
| `Stop()` | ошибку | Перестаёт принимать новые соединения и разбирает туннель. |
| `SocksAddr()` | строку | Где слушает прокси. |
| `Status()` | строку JSON | Работает или остановлен, счётчики соединений, последняя ошибка. |
| `RecentLogs()` | строку | Кольцевой буфер последних строк лога, для отладочного экрана. |

Собирать так:

```bash
go install golang.org/x/mobile/cmd/gomobile@latest
gomobile init

# gomobile порождает код, который импортирует golang.org/x/mobile/bind,
# поэтому модуль обязан его требовать. Сам транспорт от него не зависит, и в
# go.mod его намеренно нет — добавьте у себя перед сборкой биндинга.
go get golang.org/x/mobile/bind

gomobile bind -target=ios     -o Chamele0nX.xcframework ./mobile
```

**Из этого репозитория не выходит ни одного мобильного приложения.**
Биндинг даёт приложению локальный SOCKS5-прокси; чтобы превратить его в
общесистемный VPN, нужна платформенная работа, и живёт она в самом
приложении: packet tunnel provider на платформах Apple и что-то, что
превращает IP-пакеты в SOCKS5-соединения между ними.

Три вещи, которые стоит знать до того, как писать этот слой:

- **Ставьте MTU туннеля 1280.** На 1500 крупные пакеты и рукопожатия
  QUIC ломаются на путях, которые их не тянут, и выглядит это как «часть
  сайтов не открывается», а вовсе не как проблема с MTU.
- **Ведите UDP как UDP.** Библиотека packet-tunnel, настроенная нести
  UDP поверх TCP, молча выбросит DNS и QUIC. Симптом: приложения,
  которые резолвят имена через туннель, перестают работать, а приложения
  с зашитыми адресами продолжают. Сервер работает с настоящим UDP с тех
  пор, как появились UDP-типы потоков; пользуйтесь ими.
- **Исключите сокеты драйвера ложного трафика из туннеля.** Драйвер
  ложного трафика фоном ходит на сторонние домены, чтобы смесь трафика
  клиента выглядела как браузерная. Это работает, только если такие
  запросы уходят с устройства мимо туннеля. Заведёте их внутрь — получите
  эффект, обратный задуманному: ложный трафик станет трафиком туннеля и
  добавит объём, не добавив ни одного правдоподобного адресата. На
  платформах Apple — исключение их маршрутов. См. `decoy.go` и
  [THREAT-MODEL.md](THREAT-MODEL.md).

## Свой собственный клиент

Протокол описан в [SPEC.md](SPEC.md). Минимальному клиенту нужны четыре
вещи: провести TLS-рукопожатие, которое не выделяется, отправить POST по
HTTP/2 с правильной кукой доступа, обменяться открытыми ключами X25519 и
дальше говорить на уровне кадров и потоков. Реализация на Go в
`transport/chamele0nx` — около 6000 строк без тестов, и именно
формовщик здесь главное: клиент без формовки тоже подключится и тоже
будет выглядеть как VPN.
