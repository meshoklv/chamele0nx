## Where to start

- **You want to understand the idea.** [The README](../README.md), then
  [ARCHITECTURE.md](en/ARCHITECTURE.md).
- **You want to run a server.** [INSTALL.md](en/INSTALL.md), then
  [OPERATIONS.md](en/OPERATIONS.md).
- **You want to know whether to trust it.**
  [THREAT-MODEL.md](en/THREAT-MODEL.md) first, and read it to the end.
- **You want to implement a client.** [SPEC.md](en/SPEC.md).
